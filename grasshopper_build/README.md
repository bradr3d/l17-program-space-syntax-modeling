# Archived Grasshopper build

This folder preserves the previous Grasshopper/Python build and its supporting files. Current development and testing use the C#/.NET projects in the parent folder.

The shared Excel workbooks remain in the parent folder for current testing. The legacy `windows_smoke_test.py` reads them there. When opening an archived Grasshopper definition, point its workbook input at the parent folder if needed; embedded definition settings have been preserved.

`WINDOWS_SETUP.md` describes the historical Grasshopper setup and known reader issues. Stored results describe earlier runs and have not been regenerated during this reorganization.
